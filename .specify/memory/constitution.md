# Project Constitution

## Purpose
Build a reliable, maintainable subscription and bill tracking product that helps users understand recurring expenses, avoid missed payments, and review financial activity quickly.

## Principles
- Prefer clear user workflows over decorative UI.
- Keep route structure and navigation predictable.
- Protect user account boundaries and authentication flows.
- Make data models explicit before building complex screens.
- Document decisions that affect architecture, workflow, or team coordination.

## Team Agreements
- Work from private sub-branches and regularly merge approved `main` updates.
- Pull from `main` before merging or pushing feature work.
- Resolve conflicts locally and verify the app before opening or updating merge requests.
- Use clear commit messages that describe the actual change.
- Keep documentation files current when implementation details change.
