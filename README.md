# Smart Bill & Subscription Tracker

## Overview
Smart Bill & Subscription Tracker helps users manage recurring subscriptions and track monthly expenses.

## Features
- Track subscriptions
- Monitor recurring payments
- Detect spending patterns
- View subscription summaries
- Manage bill reminders

## Technology Stack
- Frontend: HTML, JavaScript
- Backend: Python
- Database: SQLite
